# ETracker

ETracker is a student-focused expense tracking web prototype that helps users understand how their money flows.

## Project purpose

The app is designed to help students:

- Track spendings
- View recent transactions
- Compare account activity
- Review monthly analytics and spending categories

## Included pages

- `home.html` — landing page introducing the product for new users
- `Dashboard.html` — offers summaries of account actions
- `Accounts.html` — account management page
- `Imports.html` — import and data management page
- `analytics.html` — spending insights and charts
- `settings.html` — theme and data retention preferences

## Tech stack

- HTML5
- Tailwind CSS

## Notes

This project is a prototype and focuses on UI/UX design with no functionality whatsoever.
